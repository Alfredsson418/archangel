<h3 align="center">About</h3>

The goal of this project is to build a open source firewall that can rival the UniFi echosystem in user experience.



# Software Features
- [ ] Basic firewall routing
- [ ] Basic DNS Resolver
- [ ] Basic DHCP Server
- [ ] Device discovery
- [ ] Deep Packet Inspection
- [ ] Device Enrollment (requires additional projects, like raspberry PI can act as a AP)
- [ ] Web based frontend
- [ ] Port discovery

And more...
